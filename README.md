# Hangar

Hangar is a desktop app that keeps track of every project folder you have: which ones you are working on, which ones went cold, and which ones hold work that was never committed or pushed. Each project opens with an editor, Git, terminals, its running processes and Claude Code in one window.

**Website:** https://caoquyen1913.github.io/hangar-app/

## Download

Installers for Windows (`.exe`, `.msi`), macOS (`.dmg`, Apple silicon and Intel) and Linux (`.AppImage`, `.deb`) are on the [Releases](https://github.com/Caoquyen1913/hangar-app/releases/latest) page.

The installers are not signed yet:

- **Windows:** if SmartScreen stops the installer, choose *More info*, then *Run anyway*.
- **macOS:** the first time, right-click Hangar in Applications and choose *Open*. If macOS says the app is damaged, run `xattr -dr com.apple.quarantine /Applications/Hangar.app`.
- **Linux:** make the AppImage executable (`chmod +x`) and run it.

This repository holds the website and the release files. Report problems in [Issues](https://github.com/Caoquyen1913/hangar-app/issues).
